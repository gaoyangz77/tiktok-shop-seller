# Review sales performance

1. Confirm shop set, date range, store timezone, currency and the merchant's question.
2. Use backend order-sales statistics, SKU performance, inventory analysis or BI
   catalog/data. Discover available metrics rather than inventing BI keys.
3. Align metric definitions and periods. Distinguish gross sales, net sales, refunds,
   orders and units; incomplete pages or delayed pipelines are not complete totals.
4. Summarize meaningful changes and product/channel contributions only where data
   supports them. State snapshot times, unavailable metrics and assumptions.
5. Recommend a small set of next investigations or operational actions. Analysis
   does not authorize price, campaign or inventory writes.
6. If the merchant wants a retained report, save a dated conclusion/decision memo,
   not a synchronized dashboard or copied finance ledger.

Reuse TK Copilot's existing financial/analytics pipelines. Do not reconstruct them
from raw transactions or invent attribution that the tools did not supply.
